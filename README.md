# Monsterreise – technischer Neustart 1.0.0-dev.1

Statische HTML5-Canvas-2D-Engine, **ohne** Codeübernahme aus alten Versionen. Zum lokalen Start im entpackten Ordner `python3 -m http.server 8000`, danach `http://localhost:8000` öffnen. Alternativ direkt als GitHub-Pages-Repositoryinhalt veröffentlichen (index.html im Root). Tests: `npm test` (keine npm-Installation erforderlich). Steuerung: WASD/Pfeiltasten oder Bildschirmknöpfe. Blaue Felder sind Übergänge, goldene Felder Treppen. Die Karten sind technische Testlayouts und nicht kanonische Geografie.

**Wichtig:** Die erste Version ist ein Engine-Prototyp, kein fertiger Prolog. Browserprüfung und Tests siehe TESTREPORT.md. Keine PokeAPI-Daten oder fremden Grafiken enthalten.
